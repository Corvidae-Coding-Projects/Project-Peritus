# H4 release contract assets

This directory contains checked, non-evidentiary schemas and templates for H4 release assembly.
Nothing checked into this directory claims that a release candidate was built, signed, audited, or
qualified. Actual evidence belongs in a candidate-specific external evidence root and is admitted
only after hashing, binding, and detached-signature verification.

- `schemas/` defines the stable JSON interchange boundaries.
- `templates/` provides deliberately incomplete operator inputs.
- `assets/` documents the externally generated artifact layout.

Canonical machine documents are compact JSON generated by the H4 crates. Pretty-printing is a
display operation and must not be substituted for the bytes whose digest or signature is recorded.
