# Peritus release license notices

This checked template is not a license inventory. H4 release assembly replaces it with the
deterministically rendered `LicenseNoticeDocument` built from the reviewed component list.

For every project or third-party component, the generated document records:

- canonical component identity and exact version;
- concluded SPDX license expression; and
- required copyright, attribution, and notice text.

An empty notice set is invalid and cannot enter the H4 documentation inventory.
