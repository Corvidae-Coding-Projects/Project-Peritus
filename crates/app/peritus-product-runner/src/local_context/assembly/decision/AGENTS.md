# Conservative decision-view compiler

## Responsibility

An opt-in projection of current committed local context into exact evidence cards, current
host state, broad model-derived working entries and complete required native exchanges. It
does not admit tools, cache qualification, change C6 canonical validity or replace candidate
checks. `DecisionViewPolicy::History` remains the default.

| File | Role |
| --- | --- |
| [mod.rs](mod.rs) | Compiler orchestration and explicit current-state fallbacks. |
| [index.rs](index.rs) | Suffix source index, original argument locators, exact inspection deduplication and source-root digest. |
| [frontier.rs](frontier.rs) | Active working/dependency priorities; model focus never proves independence. |
| [bindings.rs](bindings.rs) | Current content and identity bindings for every supplied file read, including undeclared dependencies. |
| [dependencies.rs](dependencies.rs) | Current managed-candidate and input constraints for the originating request; direct, pending, external, ignored and unknown inputs require recheck. |

| [key.rs](key.rs) | Versioned content-free reconstruction identity and complete final ModelRequest fingerprint diagnostics. |

## Working in this area

Read [the parent assembler](../../assembly.rs), current callers and source policy before
changing selection. Unknown derived dependencies remain broad; any excluded supplied evidence
withholds unscoped derived/native history. Reviewer sources remain in the reviewer's own
namespace. An artifact digest or delivered page never grants current-state or acceptance credit.

The indexes are derived process state, rebuilt from the existing checkpoint and journal.
Immutable source classification advances with the suffix index; it never substitutes for current
candidate capture, source admission or permission checks. Host-bound entries use the version-6
reader floor and remain guarded after compilation rollback. A public assembly starts an unbound
request epoch; internal batch/guard checkpoints preserve the active response's origin.
Opaque/native dependencies retain the history selector when current restrictions allow it;
restricted views page readable exact sources instead. Both selectors preserve logical history
and ordinary checkpoint boundaries. See [local-context navigation](../../AGENTS.md).
