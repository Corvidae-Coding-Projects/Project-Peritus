# Peritus workspace

Mode: Operate. Conversation-first desktop web workspace with a responsive single-panel phone layout. Users operate simultaneous local projects through the existing Peritus daemon. Full physical theater is explicitly approved; reduced motion and readable long-form content are required.

## Direction contract

THESIS: The workspace is a Nixie laboratory console. Project channels and nested sessions are real operational bindings, with observed counts rendered in depth-layered tube banks.

OWN-WORLD: Blackened steel chassis, gunmetal panel edges, warm orange active cathodes, ivory text, engraved condensed labels, recessed inputs and substantial molded keys. Glass belongs only to the numeric instrument.

STORY: Identify the project and session, inspect files, converse, and act on observed outcomes. Git and advanced harness controls are always reachable.

FIRST VIEWPORT: A full-width branded top plate with live counters; project channel tabs below; a file drawer at left, a generous central session display with nested tab levels and a bottom composer, and a compact controls panel at right.
