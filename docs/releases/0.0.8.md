Release source: `develop`, including implementation commit
`4a23259d1` and the 0.0.8 version/changelog update. Release target: `main`;
release tag: `v0.0.8`.

## Changes

- Fix macOS daemon discovery when the installed command is launched through its
  separate `~/.local/bin/peritus` symlink.
- Preserve ordinary-folder sessions on reconnect and handle larger GitHub release
  metadata during updates.
- Reduce repeated long-history work and hidden-panel polling in active conversations,
  and retain the reason for a disconnected client after its temporary notice expires.
- Execute native RSI candidates and separate evaluators, publish actual evidence,
  select against a frozen policy, and require fresh approval for promotion and rollback.
  Recover durable inputs, outputs, ownership, and approval lineage across interruption.
- Respect real-testing improvement directives and complete reviewed no-patch investigations.
- Preserve required steering and blocker context while compacting generated fixer evidence.
- Add Option/Alt word editing and delivered Cmd/Super line navigation throughout shared
  terminal editors, plus optional enhanced-keyboard negotiation and cleanup.
- Explain conversation modes beside terminal and web composers, in help and accessible
  descriptions, including read-only restrictions and explicit switching.

## Compatibility and scope

Back up the complete Peritus state directory before updating and stop active work
gracefully. Existing records are retained; older executables cannot be assumed to read
records written by newer versions. Publication does not update or restart an installed
daemon or client.

Native macOS/cmux shortcut interception and physical keyboard delivery remain outside
the Linux composer campaign. Native RSI process results do not establish general model
quality or universal statistical improvement. The exact Running-before-analysis crash
window and a fresh multi-hour daemon soak remain unobserved. The linked reports retain
their precise limits; this release makes no claim of complete application coverage.

The WebUI remains an optional source-built companion. Browser control requires the
optional Playwright/Chromium runtime. Native desktop control supports Linux. Debian/RPM
packages and Windows/macOS native desktop control are not included.
