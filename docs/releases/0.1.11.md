# Peritus 0.1.11

Peritus 0.1.11 completes the boundary between the product and separately maintained Rust modules.
Peritus now exposes a generic source-built module interface; the Red Team module and all of its
security-specific behavior live in the Peritus Module Market.

- Give installed modules scoped source access and disposable application laboratories without
  granting authority over the user's original checkout.
- Execute opaque module workers with explicit arguments, runtime features, environment, resource
  ceilings, cancellation, cleanup, and bounded result transport.
- Allow a module to request managed browser automation while keeping its browser campaign,
  protocol adapters, credentials, canaries, findings, and report semantics inside that module.
- Build, install, enable, disable, refresh, and remove source modules through the same generic
  module lifecycle.
- Remove Peritus's former Red Team-specific adapter dispatch, owned-job implementation, and stale
  dependency-preparation command.
- Improve retained long-running work with reusable observations, compact evidence, provider
  recovery, and clearer terminal visibility for active work and steering.

The final Module Market package was built and installed into an isolated Peritus environment and
operated through the native TUI. Its browser campaign completed 28 actions, observed 28 requests,
and retained seven findings. The disposable laboratory stopped and tore down successfully. Both
the module's teardown verification and an independent SHA-256 comparison showed that the original
application source remained byte-for-byte unchanged.

During that campaign, real execution exposed and drove fixes for worker path length, process/open
handle ordering, browser process limits, virtual-memory enforcement, private `/proc` and `/dev`
access, and required bounded Linux syscalls. The final worker still uses deny-by-default filesystem,
network, process, and seccomp boundaries.

The exact Chrome-extension-free release candidate passed formatting, strict Clippy for the affected
CLI, daemon, product-runner, computer-tool, and Linux sandbox crates, and optimized native builds.
No unit, mock, formal-verification, or repository qualification suites were run. Browser evidence is
for managed Chromium on Linux; other browser engines and application-specific authenticated logic
remain outside that bounded campaign.

Rust and WebUI metadata advance together to 0.1.11. The Red Team module is distributed separately
from `https://github.com/Corvidae-Coding-Projects/Peritus-Module-Market`; installing Peritus alone
does not bundle that module's source or specialized security behavior.
