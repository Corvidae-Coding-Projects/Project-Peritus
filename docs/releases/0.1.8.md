# Peritus 0.1.8

This release repairs host-side causes of repeated reading and lost task progress. The release
source is `develop` merged into `main`, tagged `v0.1.8`.

- Successful approved external-reference reads remain available in the next provider request,
  with current authorization and file identity checked. Normal `./` path aliases work consistently.
- Same-task retry, compaction, and restart preserve role-owned decisions, next steps, and settled
  effects. A read followed by an owned edit or deletion remains explicitly historical evidence;
  it cannot establish the current file state or trigger recreation of a deleted temporary file.
- Independent reviewers retain delivery coverage for immutable evidence across invocation
  boundaries. Another role or changed source digest gets separate coverage; raw archived output
  alone does not count as delivered evidence.
- Repeated-outcome tracking covers memory wrappers, skills, workspace operations, and refusals,
  including rotating read cycles. Unchanged evidence already in view produces a compact receipt.
  No-op edits and unrelated commands do not reset grounding. No read, task, or token quota is added.
- Host-generated feedback stays distinct from user requirements. Terminal-output corrections
  repair the rejected contract using retained evidence instead of ordering fresh discovery.
- Current permissions and private-source exclusions apply to original archive results, encoded
  tool-message wrappers, chained retrievals, and source-backed working state. Historical bytes
  never grant access. This is source-backed admission, not erasure of all mentions from prose.
- Local implementation handoff and candidate inspection require Read/Write rather than unrelated
  permissions. Declared external commands still check current Process permission before launch;
  web and browser tools retain their own capability requirements.
- Provider-envelope fitting retains typed UTF-8 document pages, exact ranges, digests, and
  continuations instead of raw serialized-JSON prefixes. Fitting reuses the selected payload
  rather than repeatedly loading it during the search for a fitting page.

The [real-testing report](../testing/read-loop-recovery-real-2026-10-20.md) records all twelve
original findings and additional failures found and repaired through actual operation.
The [compact evidence](../testing/read-loop-recovery-evidence.json) records the exact native
artifact and results. Portable replayers and preserved original failures are under
[read-loop-recovery](../testing/reproducers/read-loop-recovery/README.md).

Completed evidence includes 1,120 actual public-API actions: 765 main regression/generated
actions, 48 immutable-review actions, and 307 independent boundary/archive/privacy actions.
The independent campaign used 40 native launches. It includes same-size changes with restored
mtime, replacement and deletion/recreation, cold reopening, role separation, Read/chmod
revocation, Unicode ranges, aliases, and private archive chains.

A fresh authenticated official-provider conversation → design → edit → independent review run
reached Accepted in 14 provider requests and 13 tool calls, with workspace Process and Network
disabled. Its exact patch, deliberate no-op, temporary write/read/delete, unchanged unrelated
files, and retained historical read were independently checked. The external fixture owner
then built and ran the resulting CLI: exact output `After\n`, empty stderr.

These are bounded Linux observations, not a multi-hour autonomous campaign or a guarantee of
every model's discretionary behavior. TUI/WebUI journeys and other providers' live inference
were not repeated for this release. The native packaging workflow builds all six supported
OS/architecture packages and operates installation/offline terminal startup on the four Unix
hosts. Existing behavioral evidence is reused; no unit, mock, formal-verification, or repository
qualification suite is part of this release workflow.

Rust and WebUI version metadata is synchronized to 0.1.8; external dependency pins are unchanged.
Deep Research remains separately distributed through the module market with the same wire contract.
