# Peritus 0.0.7

Release source: `develop` at `ac21e69b2a1f15ec204dfc4742f7a64eeb7895ea`, plus
the 0.0.7 version/changelog update. Release target: `main`; tag: `v0.0.7`.

## Changes

- Real browser automation and Linux desktop control, including screenshots, semantic controls,
  persistent isolated sessions, and explicitly selected existing browser/app sessions.
- Larger document reads, transport-aware context selection, and artifact-backed durable
  conversation continuations that avoid the former run-snapshot size failure.
- Historical process-result recovery and provider-settings restart repairs.
- Delayed-heartbeat handling, accurate live token totals, bounded command-output previews and
  exact retained-output pages, plus actionable tool and provider-argument diagnostics.
- A missing check contract stops the fixer cycle with retained effects and an explicit handoff.

This release reuses completed behavioral campaigns for the implementation commits. The release
preparation changes versions and documentation; it adds no program behavior or dependencies.
No unit tests, formal checks, or repository qualification suites are part of this release.

- [Computer automation](../testing/computer-automation-campaign-2026-10-11.md): actual browser

- [Provider restart](../testing/real-testing-provider-restart-2026-10-11.md): copied historical

- [History/context recovery](../testing/history-recovery-2026-10-11.md): large continuation

- [Runtime friction](../testing/runtime-friction-2026-10-12.md): actual TUI heartbeat timing,
  seven native output sizes, binary pages/reopen, 37.3 MB output through the real model/host path,
  live token accounting, and safe malformed-argument rejection.

Native release jobs build Linux, macOS, and Windows archives for x86-64 and ARM64. Each package
contains the CLI, daemon, terminal interface, and native sandbox helper. The packaging path checks
manifest bytes/hashes and CLI/daemon version output, then publishes archive checksums, inventories,
SBOMs, provenance, and GitHub attestations. Publication waits for all six native packages.
The WebUI remains an optional source-built companion; Debian/RPM archives are not included.

## Compatibility and scope

Browser automation requires the optional Playwright/Chromium runtime. Native desktop control
currently supports Linux; Windows/macOS native control and arbitrary Wayland pixel injection
are not implemented. Live GUI sessions must be reopened or reattached after controller restart.
Provider limits remain effective even though Peritus has no fixed local 200,000-token ceiling.

The daemon accepts existing version-six run records and writes version-seven snapshots with
digest-checked continuation artifacts. Preserve the complete state directory when upgrading;
an older daemon cannot be assumed to read newly written snapshots. Upgrade at an appropriate
stopping point for active work. No automatic installation or daemon restart is part of publication.
