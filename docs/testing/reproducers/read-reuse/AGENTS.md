# Read reuse replay navigation

These drivers operate actual public product tools, durable context, and the memory-tool decorator. They do not substitute a read implementation or provider response. The Python fixture owner supplies source bytes and expected state transitions independently.

| File | Role |
| --- | --- |
| `consumer.rs` | Interactive native consumer, reusing the existing context consumer's production runtime setup. |
| `link.py` | Link that consumer against the freshly built production dependency cohort. |
| `replay.py` | Concrete and seeded read/edit/compaction/restart/permission/role scenarios. |
| `README.md` | Contract, replay commands, and evidence limits. |
| `observed-results.json` | Compact final scenario, byte-count, source-hash, and live-run receipts. |
| `regressions.json` | Concrete early-build failures, stable expectations, and replay command. |
