# Original working-state inputs

## Responsibility

Anonymous generated v1 canonical snapshots retained from the original failing public consumer.
`manifest.json` records each uncompressed length and SHA-256. The three `.pwms.gz` files preserve
65,535 sources, a state over 8 MiB, and 512 entries. Decompress through the parent build helper;
do not replace them with snapshots generated by the repaired encoder.

| [original-65535.pwms.gz](original-65535.pwms.gz) | Compressed original v1 snapshot exercising 65,535 retained sources. |
