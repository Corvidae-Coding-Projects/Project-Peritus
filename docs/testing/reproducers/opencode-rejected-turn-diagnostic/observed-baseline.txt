# Observed baseline — OpenCode rejected-turn diagnostic

Captured 2026-10-20 on WSL2 Debian, Peritus 0.1.4 built from this checkout
(`cargo build --offline -p peritus-cli`), with the provider-level and agent-level consumers built
offline into `target/`. Every block below is verbatim stdout from
`docs/testing/reproducers/opencode-rejected-turn-diagnostic/replay.py`, which answers the adapter
with `docs/testing/reproducers/opencode-rejected-turn-diagnostic/scripted-opencode.py`. No network
access, credential use, or vendor inference occurred.

The consumer names each recorded correction as `CORRECTION` and each recorded public activity as
`ACTIVITY`. `rejected_bytes` counts the complete refused reply; `rejected_truncated` is false while
the reply stays within the 16 KiB retention bound.
