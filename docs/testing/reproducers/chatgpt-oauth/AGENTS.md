# OAuth and steering replay navigation

These programs drive production interfaces with disposable state and actual provider requests.
A successful build or saved login is not proof of inference, refresh, host commands, or revocation.

| File | Responsibility |
| --- | --- |
| [README.md](README.md) | Exact build/run inputs, expected boundaries, request costs and coverage limits. |
| [consumer.rs](consumer.rs) | Actual browser OAuth, protected account reload, live model catalog and three inference/tool round trips. |
| [link.py](link.py) | Select and link the production dependency cohort without adding a test workspace target. |
| [tools.py](tools.py) | Actual file plans, native commands and edits with independent filesystem/module oracles and retained scope failures. |
| [steering.py](steering.py) | Start its own daemon, submit input while official inference is pending, and inspect durable accounting and public output. |

The steering program consumes the existing negotiated IPC client under
[incremental-context](../incremental-context/AGENTS.md). It never selects an existing user run.
