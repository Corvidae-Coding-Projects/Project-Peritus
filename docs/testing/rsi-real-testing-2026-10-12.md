# RSI real testing — 2026-10-12

Status: the bounded native campaign passed after five confirmed defects were repaired; production F0 remains incomplete. Testing began October 12 and continued October 13 against isolated daemons and a disposable Git-backed copy of Peritus. The separate E3/F0 campaign confirmed a missing production execution boundary; see [its report](rsi-f0-real-2026-10-12.md). The campaign uses actual interfaces rather than unit tests, mocks, formal verification, or canned qualification fixtures. The native application initially selected conventional automatic checks despite its directive; that observed handoff failure is recorded below and corrected on the final runtime. No unit tests were generated or executed. This is not a claim of full application, platform, or statistical promotion coverage.

## Scope and independent expectations

The inbox must collect suggestions without inference or patch generation, preserve run evidence and normalized identities, retain dismissal, reject invalid sources and targets, launch exactly one isolated evaluation, and expose its actual workbench and patch. New evaluation directives must govern real-interface acceptance. Retry and upgrade must preserve already acknowledged operation payloads. A statistical F0 candidate campaign must deliver its real schedule and execute, publish, select, and promote only through the documented authority boundaries.

The seed defect is confined to the disposable source clone: Cargo defines package version `0.0.7`, but the CLI source is altered to print `peritus 0.0.0`. A separately compiled baseline confirms this mismatch. Version output must use the package metadata; help and invalid-argument behavior must remain unchanged. No seeded fault was introduced into the product checkout.

The final native replay produces five explicit `NOT EVALUATED` observations for excluded conventional commands, passes its selected internal checks, and reaches independent review. Missing required execution records still cannot pass the public plan/report consumer. Review after recovery detected missing current baseline receipts and a replay document dependent on a temporary artifact.
