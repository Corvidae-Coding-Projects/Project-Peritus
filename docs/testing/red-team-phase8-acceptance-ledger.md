## Explicit limits

- Linux x86-64 GNU is the only source-build and containment environment claimed here.
- The trusted runtime adapter proves exact canary disclosure for the recorded fixtures. Other
  interfaces remain analysis-supported, inconclusive, blocked or unexamined without a matching
  host adapter.
- The copied browser repository is a bounded brownfield sample, not a security certification.
- Cryptography and key lifecycle is deliberately unexamined in the final campaign.
- No unit tests or formal verification were run.
