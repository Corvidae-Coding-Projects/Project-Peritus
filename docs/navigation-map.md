# Codebase navigation map

## Scope and method

This documentation pass covers every directory containing tracked repository material and all of its parent directories, including hidden configuration, Rust sources, browser sources, compatibility cases, packaging, and retained evidence. Local build output, dependency caches, Git internals, external reference checkouts, generated local skill integrations, and other worktrees are outside this repository-managed boundary.

At the documentation baseline there were **5740 tracked files**, **1171 directories**, **79 active Cargo workspace members**, and **126 existing READMEs**. Each directory now has a conventional uppercase `AGENTS.md` waypoint. Existing READMEs were refreshed; 14 human overview READMEs were added at layer/skill boundaries.

File roles come from actual module comments, API declarations, Cargo manifests, document titles, script docstrings/entry names, and fixture configuration. The main product/runtime/browser junctions have additional hand-written responsibility and cross-owner routes. This is a navigation inventory, not a whole-code correctness review or a claim of testing coverage. No builds, program runs, test suites, or verification gates were performed for this documentation update.

Active packages are identified by current root Cargo membership. README-only retired components and formal/qualification evidence remain explicitly historical. Payloads, hashes, schemas, implementation files, manifests and archived run outputs are unchanged.

## Maintaining the map

Interactive Design mode is owned by `peritus-product-runner/src/guided_design.rs` and
`execution/conversation/design.rs`, reached through A3 mode tag 5 and the existing daemon
conversation entrypoint. The [guided design replay](testing/reproducers/guided-design/AGENTS.md)
operates actual terminal conversations and their downstream CLI deliverable.

When adding or moving code, update the local file table and the immediate parent child-area table. Give a responsibility and an entry point, rather than restating the filename. Keep product composition, pure contracts, concrete effects, presentation, compatibility input, replay tooling, and historical evidence visibly distinct. A folder map should let the next agent choose where to read without guessing which subsystem owns the behavior.
