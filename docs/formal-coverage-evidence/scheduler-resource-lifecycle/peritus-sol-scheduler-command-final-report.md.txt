## Completed production guarantees

- The actual reservation capacity and ownership invariant remains connected to the production
  scheduler state, selected feasibility, actual reservation insertion, and all five release
  outcomes established at frozen244.
- Reservation readiness is strengthened to a bidirectional lifecycle relation: every live
  reservation names active work, and Reserved, Running, or Cancelling work retains its matching
  reservation with the expected started state. The production start acknowledgement and release
  mutations preserve those relations.
- Actual worker and work insertion functions preserve the reservation invariant under exact
  identity-absence and inactive-work conditions. This is a mutation theorem; admission caller
  closure remains listed below.
- `SchedulerCommandKind` is the actual command declaration under Verus, with an exact semantic
  `Clone` over every variant. Its private leaf has the narrow ghost-only `missing_docs` annotation
  required by the pinned projection generator; ordinary Rust documentation checking remains on.
- `SchedulerBinding`, `SchedulerState`, `WorkRecord`, and worker state use semantic clone
  implementations covering every authoritative field, including terminal state.
- Production reducer routing uses verified deterministic cores for Pause, Resume, Drain,
  RetryWork, ExhaustWork, AcknowledgeStart, CompleteWork, FailWork,
  AcknowledgeCancellation, and AbandonDispatch. These cores preserve reservation readiness and
  the proved binding, scheduler-phase, worker, live-reservation, and used-dispatch frames for
  their applicable outcomes.
- Regression coverage exercises all five release paths, retry then re-reserve, cancellation
  acknowledgement, dispatch abandonment, rejection rollback/error precedence, terminal payloads,
  and deterministic replay of those traces.
- Verified binary-search lookups prove that every returned `Some` value has the requested actual
  identity. The converse for `None` is not claimed.

These guarantees are a bounded reservation and command-kernel slice. They do not establish full
reducer, replay, effect, or system termination.
