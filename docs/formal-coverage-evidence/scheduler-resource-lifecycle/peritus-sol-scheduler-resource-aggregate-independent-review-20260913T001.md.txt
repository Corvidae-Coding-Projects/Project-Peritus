## Source findings

- Canonical addition uses the actual production-called merge kernel. It retains ascending unique kinds, exact per-kind mathematical sums, and explicit zero-valued entries. Any shared-dimension `u64` overflow is detected during merge before the dimension ceiling is tested, preserving `ResourceConflict / resource addition overflowed` over `LimitExceeded`. A nonoverflowing union above the caller ceiling maps to the prior limit error.
- Subtraction retains the prior order: scan left dimensions for underflow first, then validate the subtrahend's zero-quantity sentinel as an absent dimension. This covers wire-decoded explicit zero quantities: zero minus positive reports underflow; zero minus zero reports the existing absent-dimension error. A successful empty difference returns `None`; a nonempty result retains exact ordered differences without revalidating through a new runtime guard.
- `ResourceVector::quantity` now uses verified binary lookup and returns the exact stored value or the same absence-as-zero sentinel. Constructor admission still checks empty/oversized before ordering, preserving error priority.
- Each global or worker capacity predicate call folds reservation resources into a canonical aggregate and checks requested dimensions against that aggregate. Representable folds equal the mathematical reservation sums. If the fold cannot represent a sum, the implementation invokes the exact prior `u128` per-reservation fallback; aggregation failure cannot itself admit or reject work.
- The public selection loop, candidate precedence, first-worker order, worker-count calculation, and `>4096 => false` defensive branch are unchanged. The aggregate and fallback paths prove equality with the same global/worker fit predicates, so valid admitted states keep the same feasibility result and deterministic selection order.
- No new public executable precondition, rejection guard, assumption, admit, axiom, external body, verifier substitute, or lint suppression appears in the ten paths. Public addition/subtraction remain ordinary wrappers that call the verified kernels and map their outcomes to the prior exact errors; the wrappers themselves do not carry Verus Result contracts.

The supplied ignored release fixture constructs valid dense canonical scheduler states and calls public `select_next` and public dispatch decision logic. Production source hashes match the frozen repair; the only timing overlay adds the ignored probe module. The measurements are bounded observations on one machine, not an asymptotic theorem.

The algorithm aggregates once per capacity predicate invocation, not once for an entire selection pass. Sparse and multi-candidate workload latency remains unmeasured and is not claimed.
