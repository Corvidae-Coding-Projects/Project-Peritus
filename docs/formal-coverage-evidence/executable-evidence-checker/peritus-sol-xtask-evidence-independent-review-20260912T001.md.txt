## Source correspondence reviewed

- `api_contract/declaration.rs` reuses the existing comment/literal-safe reference lexer, the pinned
  Verus signature grammar, and the existing function-header scanner. It records actual mode,
  lexical `verus!` enclosure, nesting, configuration, and exact test/ignore state.
- `trust_lexer::declaration_paths` retains duplicates and emits one ordinal for every same-name
  function, including locals before local filtering. `manifest_symbol::owned_function_declarations`
  pairs that ordinal with the same ordered declarations, then constructs the exact crate/module/
  associated-owner path. Exact-path multiplicity must be one.
- `ManifestContext::validate_source` remains the source of Cargo package ownership and regular,
  non-symlink repository-path validation. The symbol root must still match `owning_crate`, and the
  exact canonical evidence command check is unchanged.
- Cargo-test evidence requires an exact non-ignored `#[test]`, no function nesting, and only
  unconditional or exact `cfg(test)` activation. Ordinary functions, ordinary `const fn`, other
  conditional paths, `cfg_attr`, and ambiguous declarations produce diagnostics.
- Cargo-Verus evidence requires one unconditional non-local declaration inside `verus!` and an
  exact parsed Exec, Proof, or Spec mode. Comments, string literals, local functions, alternate
  owners, and duplicate same-path declarations cannot supply that declaration.
- `registered_proof_symbols` resolves each obligation `verus-proof` locator again from source and
  carries its parsed mode into the fresh strict package scope. The compiler report checker requires
  exact selection plus a successful same-symbol `exec` or `proof` query for executable/proof
  evidence. Spec evidence retains the explicitly documented selected-function check. Failed,
  partial, wrong-toolchain, sibling-root, absent-query, and conflicting-mode reports still fail.
- The trust scanner's prohibited-construct scan is unchanged. Its declaration-path helper changed
  only from deduplicated paths to exact path/ordinal occurrences, so `assume`, `admit`, `axiom`,
  external-body, and related escape accounting is neither suppressed nor newly authorized.
- No production crate, workflow, obligation record, manifest schema, dependency, or public API is
  changed. The test-only module split preserves behavior and restores the source-layout gate.
