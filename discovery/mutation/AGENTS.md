# Mutation testing navigation

`run.py` inventories all active root production Rust and runs cargo-mutants in a disposable source workspace, with each selected production package's own tests and the required model baselines. `tests/codec_diagnostics.rs` preserves actionable diagnostics across reachable failure families. `tests/public_models.rs` bridges the existing 42 independent public model checkers to Cargo's test interface. `src/bin/peritus-mutation-agent-driver-child.rs` provides the real child-process entrypoint required by AgentDriver crash-cut checks, and `tests/agent_driver_child.rs` protects that bridge. `Cargo.toml` is an optional nested discovery package and never a release dependency. `.cargo/mutants.toml` owns mutation execution defaults; `run.py` owns production file selection and inserts selected production packages into the disposable campaign's test list. `README.md` explains scope, sharding, output and unexercised owners/platforms.

Keep source fixtures and exact oracles here. Generated trees, compiler products, candidate diffs and run evidence belong in the requested external output directory. Never treat zero tests, a missing selected-model marker, a timeout or an unviable mutant as successful fault detection.
