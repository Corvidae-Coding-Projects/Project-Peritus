# Stage 6 owned process output contract

`stage6::process_output` generates bounded byte payloads, separate stdout/stderr selection, chunk/window/spool/stream/event limits, overflow actions, and lifecycle operation histories. The independent policy oracle rejects zero or inconsistent operational bounds and checks that successful `OutputPolicy` construction preserves every selected limit. The lifecycle oracle replays legal and illegal phase changes, spawn failures, and competing stop requests through public `LifecycleState`, requiring exact first-trigger preservation and one terminal acceptance. An independent byte model computes the observed length, durable spool prefix, dropped count, and in-memory tail for each single-stream payload.

The model alone does not observe process output: `OutputAccounting`, retained windows, and spool writers are crate-private. The separate native Linux output matrix uses the public `ExecutionGateway`, `OwnedProcess::control()`, and `TerminalResult::output()` to compare actual spool bytes, retained tail, per-stream accounting/completeness, and terminal outcome with the independent byte model. It launches only caller-selected shell/bubblewrap/helper/cgroup resources through disposable authority, and runs one active stream per case to avoid nondeterministic inter-stream read ordering. A terminated overflow case checks the output-limit first trigger and owned-tree cleanup; continuing overflow cases require exact observed/dropped counts and normal exit. A sibling canary remains unchanged. The matrix is Linux-specific and does not qualify macOS or Windows process backends.

The deliberate calibration mutation in `calibration/stage6-process_output.patch` removes the chunk-versus-window bound from `OutputPolicy::new`. `calibration()` supplies a chunk larger than its retained window while otherwise respecting the spool bound; fixed examples and generated cases reject the original and accept the mutant. The mutation remains unapplied outside calibration runs.
